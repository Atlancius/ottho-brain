# Prise en main (à expliquer après l'installation)

Court, concret, adapté aux packs installés.

## Redémarrer

Fermer et relancer Claude Code et Codex : le bloc de boot et les nouveaux
skills ne sont chargés qu'au démarrage d'une session.

## Obsidian (optionnel)

« Ouvrir un dossier comme coffre » → choisir le dossier du cerveau. Les
réglages posés par l'installation gardent des liens Markdown relatifs
compatibles avec les agents et masquent les dossiers techniques.
Web Clipper : régler le dossier de destination sur la boîte de dépôt.

## Les phrases du quotidien

- « <skill d'ingestion> » après avoir posé un article, un PDF ou une note dans
  la boîte de dépôt.
- « Note ça : … » pour une idée, une décision, une fiche.
- « Cherche dans mon cerveau … » pour retrouver une information.
- Pack rituels : « journal du jour », « revue hebdo », « capture : … »,
  « bilan mensuel ».
- Pack projets : « fiche projet … », « portefeuille », « doc-projet » dans un
  dossier de code ou de création.
- Pack méta : « crée un skill … », « rapatrie mes skills », « usage ia ».
- « Audite mon cerveau » une fois par mois.

Dans Codex, un skill s'appelle aussi par `$nom` ; dans Claude Code par `/nom`.

## Depuis n'importe quel projet

Claude et Codex lisent le bloc de boot : ils savent où est le cerveau et
cherchent dedans quand la tâche touche la personne ou ses projets. Rien à
faire de plus.

## Mettre à jour

Après une mise à jour du plugin : « répare mon cerveau » (skill
`reparer-cerveau`). Il met à jour le moteur et les gabarits non modifiés,
jamais les pages, puis rebranche Claude et Codex.

## Ce qui ne doit jamais entrer

Mots de passe, clés d'API, IBAN, relevés, pièces d'identité, santé, adresses
et téléphones privés, documents confidentiels d'un employeur ou d'un client.
Le cerveau les bloque ; ils se gèrent ailleurs (gestionnaire de mots de passe,
dossiers chiffrés).
